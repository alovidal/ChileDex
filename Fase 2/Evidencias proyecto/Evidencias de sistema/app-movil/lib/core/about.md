# **Carpeta CORE**

## Propósito:

Esta carpeta tiene como propósito contener el código que múltiples features usaran pero no le pertenecen a ninguna.

## Ejemplos:

1. **Network:** Para definir los endpoints.
2. **Error:** Para definir los errores o excepciones.
3. **Utils:** Para definir utilidades como extensiones.
3. **Widgets:** Para definir widgets reutilizables.
